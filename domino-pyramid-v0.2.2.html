Rules & controls

Use all 28 unique double-six dominoes. Rows from the bottom contain 7 horizontal, 6 vertical, 5 horizontal, 4 vertical, 3 horizontal, 2 vertical and 1 horizontal tile. Every touching number must match.

Select a tile and tap or click any empty position. Both orientations are tried automatically. If neither fits every existing neighbour, placement is refused. Tiles can be placed above gaps. Click any placed tile to return it; other tiles stay untouched. Finish checks the current 28-position pyramid. Flip preference only matters when both orientations fit. Keyboard: Tab and Enter to select or place; F changes orientation preference.

Shift Pyramid: with a tile selected, click or tap the small left or right arrow beside the seven-tile base. The selected tile stays in the tray until you invoke a shift; it is never shown in the corner extension positions. The tile turns automatically to match the exposed base end. The working pyramid shifts one position, returning only the opposite fringe tiles to the tray; all surviving tiles stay exactly where they are, even above gaps. Hover or focus an arrow to preview the returned tiles, then click or tap once to shift. Each complete shift is one Undo operation. Shifts can be repeated without limit. After a completed pyramid, return any tile to select it and continue shifting.

On small screens, Enlarge board provides bigger tiles with horizontal scrolling. The layout adapts to Android portrait and landscape viewports; the tile box keeps visible spacing and uses its own scrolling when space is constrained.

After a verified win, the local Hall of Fame stores only the solver name, country, and completion date. The full solution is encrypted locally with AES-256-GCM using an owner-supplied passphrase-derived key. Public and encrypted exports are separate; this static build does not submit data online.
