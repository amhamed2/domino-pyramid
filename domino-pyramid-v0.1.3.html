Rules & controls

Use all 28 unique double-six dominoes. Rows from the bottom contain 7 horizontal, 6 vertical, 5 horizontal, 4 vertical, 3 horizontal, 2 vertical and 1 horizontal tile. Every touching number must match.

Select a tile and tap or click any empty position. Both orientations are tried automatically. If neither fits every existing neighbour, placement is refused. Tiles can be placed above gaps. Click any placed tile to return it; other tiles stay untouched. Finish checks the whole pyramid. Flip preference only matters when both orientations fit. Keyboard: Tab and Enter to select or place; F to change orientation preference.

On small screens, Enlarge board provides bigger tiles with horizontal scrolling. The layout adapts to screen space and touch input. Progress lasts for this open page only.
